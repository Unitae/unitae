# Licensing

Unitae is licensed under the **GNU Affero General Public License v3.0** (AGPL-3.0). The full license text is in the [LICENSE](../../LICENSE) file.

## What AGPL-3.0 Means

### For Self-Hosters

You can run Unitae freely for your congregation or organization. There are no restrictions on internal use. You don't need to pay anything or ask permission.

### For Modifiers

If you modify Unitae's source code and run it as a network service (i.e., users access it through a browser), you must make your modified source code available to those users. This is the key difference between AGPL and regular GPL — it covers the "SaaS loophole."

This ensures that improvements to Unitae benefit the entire community, even when the software is hosted rather than distributed.

### For Distributors

If you distribute Unitae (modified or not), the derivative work must also be licensed under AGPL-3.0. You must provide the source code to recipients.

## Open-Core Model

Unitae follows a **Ghost-inspired open-core model**:

- **100% of the application code is open source** under AGPL-3.0
- There are no proprietary features, paid plugins, or locked tiers
- Self-hosted users get the exact same features as users on the managed platform
- Development is funded through **managed hosting at [unitae.app](https://unitae.app)**, operated by MindserIT

This model ensures:
- Full transparency — anyone can audit the code
- Full freedom — anyone can self-host without compromise
- Sustainable development — the hosted service funds ongoing work
- Community contribution — anyone can contribute to everything

## Common Questions

**Can I use Unitae for free?**
Yes. Self-hosting is free. The AGPL-3.0 license grants you the right to use, modify, and share the software.

**Do I need to share my data?**
No. The license covers the source code, not your data. Your congregation data is yours.

**Can I fork Unitae?**
Yes, as long as your fork is also AGPL-3.0 and you provide source code to your users. Note that the Unitae name and logo are trademarks — see [Trademark](trademark.md).

**Can I build a competing hosted service?**
The AGPL-3.0 license allows this, provided you comply with its terms (including making your source code available). However, the Unitae name and logo cannot be used — see [Trademark](trademark.md).
