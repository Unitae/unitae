Un document PDF s’ajoute depuis **Gérer le tableau**. Il apparaît dans une section du tableau, pour les personnes qui la voient.

## Ajouter le PDF

1. Dans la barre latérale, ouvrez **Gérer le tableau**, puis cliquez sur **Téléverser un PDF**.
2. Déposez le fichier, ou choisissez-le : un PDF de 20 Mo au plus. Son nom devient le titre, que vous pouvez changer dans **Titre**.
3. Choisissez la **Section** où il apparaît.
4. Dans **Affichage**, choisissez quand il apparaît : **Dès maintenant**, **À partir d’une date**, ou **Pas encore** pour le garder sans le montrer. Dans **Retirer le**, choisissez le jour où il disparaît ; laissé vide, il reste sur le tableau.

   ![La section Affichage : quand le document apparaît, quand il disparaît, et À la une](capture:board-pdf-display)

5. Activez **À la une** pour le mettre en tête du tableau, au-dessus des sections.
6. Cliquez sur **Téléverser**.

## Si vous déposez sans publier

Si vous pouvez déposer des documents mais pas les publier, la section **Affichage** ne propose pas de dates : un responsable du tableau décide quand votre document apparaît. D’ici là, il est **Non publié** dans la liste. Vous pouvez toujours modifier les documents que vous avez déposés.

## Remplacer un document

Pour mettre un document à jour, ouvrez-le avec **Modifier**, puis cliquez sur **Remplacer le fichier**. L’ancien fichier reste dans l’historique, et ceux qui avaient lu le document le voient de nouveau comme non lu.
