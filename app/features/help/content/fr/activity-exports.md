## Depuis la page Activité

Avec le droit de voir l’activité, sur un ordinateur ou une tablette :

1. Ouvrez **Assemblée › Activité**, puis cliquez sur **Exporter**.
2. Choisissez le **Format** :
   - **S-21 (ZIP de PDF)** : le formulaire officiel, un PDF par proclamateur, réunis dans un fichier ZIP ;
   - **Récapitulatif (XLSX)** : une feuille par mois, de septembre à août, avec les heures, le statut, les cours bibliques et le service de pionnier de chacun.
3. Choisissez l’**Année de service**.
4. Pour les fiches S-21, choisissez la **Portée** : **Toute l’assemblée**, **Un groupe**, ou **Des proclamateurs**.
5. Cliquez sur **Exporter** : le fichier se télécharge.

![La fenêtre d’export des activités : le format, l’année de service et la portée](capture:activity-export)

Le fichier ZIP ne contient que les proclamateurs qui ont au moins un rapport dans l’année. Le crédit d’heures accordé aux pionniers n’apparaît dans aucun export.

## La fiche d’un proclamateur

Avec le droit d’enregistrer l’activité, ouvrez la fiche du proclamateur et cliquez sur **Fiche S-21** : choisissez l’année de service, et sa fiche se télécharge en PDF.
