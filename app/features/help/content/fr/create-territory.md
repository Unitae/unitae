Un territoire se compose d’un numéro, d’un type et des entrées qui le forment.

## Créer un territoire

1. Dans la barre latérale, ouvrez **Territoires**, puis cliquez sur **Nouveau territoire**.
2. Choisissez le type : **Porte à Porte**, **Commerces**, **Hôtels** ou **Universités**. Le type **Téléphones** n’est proposé que s’il est activé.
3. Renseignez le **Numéro**.
4. Sur la carte, cliquez sur les entrées libres pour les ajouter au territoire.
5. Cliquez sur **Créer le territoire**.

Pour en créer plusieurs à la fois, le bouton **Créer en lot** apparaît si vous avez aussi le droit de répartir les territoires.
