Un document dynamique se construit avec les données de l’assemblée : il change de lui-même quand elles changent. Vous n’avez rien à téléverser ni à remplacer.

## Les types de documents

- **Programme** : les réunions à venir, avec leurs parties ou leurs services. Vous pouvez en ajouter plusieurs, par exemple un par type d’évènement.
- **Groupes de prédication** : chaque groupe avec son responsable, son adjoint et ses proclamateurs.
- **Pionniers** : les pionniers du moment, par type.
- **Organigramme** : les responsabilités de l’assemblée, poste par poste.

Un type n’est proposé que si l’assemblée a ces données : des groupes, des pionniers, un organigramme. Les groupes, les pionniers et l’organigramme ne s’ajoutent qu’une fois ; s’ils sont déjà sur le tableau, la ligne indique **Déjà ajouté · Ouvrir**.

## Ajouter le document

1. Dans **Gérer le tableau**, cliquez sur **Document dynamique**.
2. Cliquez sur le type de document.

   ![Le choix du type : programme, groupes de prédication, pionniers et organigramme](capture:board-dynamic-types)

3. Donnez-lui un **Titre** et choisissez sa **Section**.
4. Pour un programme, choisissez dans **Contenu** les réunions qu’il montre, avec leurs parties ou leurs services, et leur ordre. Pour un type qui utilise plusieurs plannings de services, cochez sous sa ligne ceux que le document montre : chacun s’y lit sous son nom.
5. Dans **Apparence**, choisissez la police, la couleur d’accent et, selon le type, la mise en page. L’aperçu montre le résultat, qui reste lisible imprimé, en couleur comme en noir et blanc.
6. Choisissez quand il s’affiche, puis cliquez sur **Ajouter au tableau**.

Les lecteurs voient le document comme une page, et le téléchargent en PDF avec la même mise en page.
