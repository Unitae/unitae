**Créer en lot** forme des territoires à la chaîne à partir des entrées libres : celles qui ne sont sur aucun territoire du type choisi. Chaque territoire créé, la page se vide et propose le numéro suivant.

## Créer les territoires

1. Dans **Territoires**, cliquez sur **Créer en lot**.
2. Choisissez le **Type**. Le nombre d’entrées libres de chaque type s’affiche à côté.
3. Vérifiez le numéro dans **Prochain**. S’il est refusé parce qu’un autre territoire le porte déjà, cliquez sur **Prendre**, suivi du numéro libre proposé.

   ![L’en-tête de Créer en lot : le type, le prochain numéro, les filtres et le nombre d’entrées libres](capture:territory-batch-header)

4. Sur la carte, cliquez les entrées libres du territoire, ou cherchez-les par leur adresse s’il n’y a pas de carte. Cliquez-en une encore pour l’enlever, ou **Vider** pour tout recommencer.
5. Cliquez sur **Créer**, suivi du numéro. Le territoire rejoint la liste **Créés ici**, et la page passe au suivant.

## Bon à savoir

- La recherche par rue et le bouton **Filtres** (code postal, accès) limitent les entrées montrées, pour travailler quartier par quartier.
- Les entrées dont le bâtiment n’a pas de position n’apparaissent pas sur la carte. Le lien **sans position**, à côté du nombre d’entrées libres, les liste pour les ajouter d’ici.
- **Créer en lot** ne prend que des entrées libres. Pour en prendre à un territoire existant, voyez le découpage à la main.
- Quand toutes les entrées du type sont sur un territoire, il faut de nouveaux bâtiments : ils s’ajoutent dans la prospection.
