Les territoires téléphone sont **désactivés par défaut**. Tant qu’ils ne sont pas activés, le type **Téléphone** n’apparaît pas quand on crée un territoire.

## Activer le type

1. Dans la barre latérale, ouvrez **Réglages**, puis **Territoires**.
2. Dans **Types de territoires**, sur la ligne **Téléphone**, activez l’interrupteur.

   ![La ligne « Téléphone » des types de territoires, avec son interrupteur](capture:settings-phone-switch)

3. Choisissez les rôles qui peuvent recevoir ces territoires. Sans rôle choisi, tout proclamateur peut les recevoir.

Le type apparaît ensuite dans **Nouveau territoire**.
