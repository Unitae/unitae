Un modèle de planning donne leur contenu aux plannings des réunions : les parties d’un planning spirituel, ou les services, dans leur ordre, avec qui peut les prendre. Les nouvelles réunions le reçoivent ; les plannings déjà créés ne sont pas modifiés.

## Créer un modèle

1. Dans **Réglages › Modèles de planning**, cliquez sur **Nouveau modèle**.
2. Donnez-lui un nom. Deux modèles ne peuvent pas porter le même nom : les majuscules et les accents ne comptent pas.
3. Choisissez son **Type de planning** : **Spirituel** pour des parties, **Services** pour des services.
4. Choisissez son **Responsable**, ou **Aucun responsable désigné**.
5. Cliquez sur **Créer le modèle** : il s’ouvre, vide, prêt à recevoir ses parties ou ses services.

Un modèle qu’aucun type de réunion n’utilise s’ajoute à une réunion avec **Ajouter un planning**, sur la page de la réunion.

Pour qu’un type de réunion l’utilise, ouvrez ce type dans **Réglages › Modèles de programme** : sous **Plannings utilisés**, **Utiliser un modèle** propose les modèles d’une sorte que le type n’a pas encore. Un type utilise au plus un modèle spirituel et un modèle de services. Les flèches changent leur ordre, et la croix en retire un : ses parties et ses services restent dans le modèle, et les réunions déjà créées gardent leurs plannings. Seules les nouvelles réunions suivent ces changements.

## Ses parties et ses sections

- **Ajouter une partie hors section** ajoute une partie à la fin du modèle.
- **Ajouter une section** crée une section avec sa première partie. Une section sans partie n’est pas gardée.
- **Ajouter une partie à** une section, sous elle, lui ajoute une partie. Son menu **…** la renomme, ou la supprime une fois vide.
- Une partie s’ouvre d’un clic : son nom, sa section, sa durée, **Où** elle a lieu, et les rôles qui peuvent la prendre.
- Pour changer l’ordre, faites glisser une partie ou une section ; sur un téléphone, touchez **Réorganiser les parties**.

## Les salles

Sous **Salles**, la salle principale est toujours là. Pour ajouter une salle, écrivez son nom dans **Nom de la salle** et cliquez sur **Ajouter**.

Dans une partie, **Où** dit où elle a lieu :

- **Toute l’assemblée** : dans la salle principale, une seule fois.
- **En même temps dans plusieurs salles** : la même partie, avec ses propres orateurs dans chaque salle cochée.

## Ses services

**Ajouter un service** ajoute un service, avec les rôles qui peuvent le prendre. Faites glisser un service pour changer l’ordre ; sur un téléphone, touchez **Réorganiser les services**.

## Le responsable

Le titulaire et les adjoints du rôle choisi peuvent remplir et publier les plannings créés à partir de ce modèle, sur toutes les réunions. Qui tient le rôle se change dans l’organigramme. Le nom et le responsable se changent en haut du panneau du modèle ; sur un téléphone, touchez d’abord **Modifier le nom et le responsable**.

## Supprimer un modèle

Dans le panneau du modèle, ouvrez le menu **…** et choisissez **Supprimer le modèle**. La fenêtre dit ce qui part et ce qui reste : les types de réunion qui l’utilisent n’en reçoivent plus, et les plannings déjà créés gardent leur nom, leur contenu et leurs attributions. La suppression est définitive.
