L’organigramme montre les responsabilités de l’assemblée. Chaque case est un rôle : une **équipe**, avec des responsables, des adjoints et des membres, ou un **rôle personnel**, tenu par une seule personne. Il commence par les anciens et les assistants ministériels, tenus à jour depuis les fiches.

## Créer un rôle

1. Dans la barre latérale, ouvrez **Organigramme**, puis cliquez sur **Nouveau rôle**.
2. Donnez-lui un **Nom** et, si vous voulez, une **Description**.
3. Choisissez sa **Place** : sous quel rôle il se range, ou **Hors organigramme** pour un rôle sans case dans l’arbre ni sur le tableau.
4. Cliquez sur **Créer le rôle**.

## Nommer les personnes

1. Cliquez sur la case du rôle : son panneau s’ouvre.
2. Cherchez la personne. Dans une équipe, choisissez **Responsable** ou **Adjoint**. Cliquez ensuite sur **Nommer**. Dans un rôle personnel déjà tenu, le bouton devient **Remplacer** : le titulaire change, ses adjoints restent.

   ![Le panneau d’une équipe : ses responsables, la recherche pour nommer quelqu’un, et ses membres](capture:organigram-role-panel)

Un rôle peut être donné à un proclamateur qui n’a pas de compte. Les membres d’une équipe s’ajoutent dans l’onglet **Équipes** : une case cochée ajoute la personne, et c’est enregistré aussitôt.

## Modifier ou déplacer un rôle

Dans le panneau du rôle, **Modifier** change son nom, son type, sa description et la **Note sur le tableau**, imprimée sous le rôle dans l’organigramme du tableau d’affichage. En bas du panneau, **Place dans l’organigramme** le rattache sous un autre rôle, le monte ou le descend, ou le sort de l’organigramme. **Supprimer le rôle** n’est possible qu’une fois ses rôles rattachés déplacés.

Ce que chaque rôle permet de faire dans l’application se règle dans **Réglages › Rôles et autorisations**.
