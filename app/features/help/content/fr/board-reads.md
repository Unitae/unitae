Dans **Gérer le tableau**, la colonne **Lu par** donne, pour chaque document, le nombre de personnes qui l’ont lu sur celles qui le voient : par exemple « 12 sur 40 ». Un document compte comme lu dès qu’une personne l’a ouvert.

## Voir qui l’a lu

1. Dans **Gérer le tableau**, cliquez sur le nombre de la colonne **Lu par**, ou choisissez **Lectures** dans le menu **…** du document.
2. Le panneau **Lectures** s’ouvre à côté de la liste. **Pas encore lu** et **Lu** séparent les deux listes, rangées par groupe de prédication.

   ![Le panneau Lectures : qui a lu le document et qui ne l’a pas encore lu, groupe par groupe](capture:board-reads-panel)

## Ce qui est compté

- Seules comptent les personnes qui voient la section du document, avec un compte actif.
- Quand un PDF est remplacé, ou quand les données d’un document dynamique changent, le document redevient non lu pour ceux qui l’avaient lu : ils passent dans **Pas encore lu**, avec la mention « a lu une version précédente ».
