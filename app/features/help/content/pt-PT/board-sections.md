O quadro de anúncios é feito de secções, pela ordem em que **Gerir o quadro de anúncios** as lista. Cada secção indica quem a vê, e os seus documentos aparecem pela ordem da lista.

## Criar uma secção

1. Em **Gerir o quadro de anúncios**, clique em **Secção**.
2. Dê-lhe um **Nome**, tal como aparece no quadro.
3. Em **Visível para**, escolha **Todos**, ou **Algumas funções** e as funções que a veem. O formulário indica quantas pessoas a vão ver.
4. Clique em **Criar secção**.

Uma secção reservada a algumas funções também esconde os seus documentos das outras pessoas.

## Arrumar as secções

Na linha de uma secção, **Editar secção** muda o nome e quem a vê. O menu **…** propõe **Mover para cima**, **Mover para baixo** e **Eliminar secção**.

![A linha de uma secção, com Editar secção e o menu: Mover para cima, Mover para baixo e Eliminar secção](capture:board-section-menu)

Para eliminar uma secção que tem documentos, escolha movê-los para outra secção, ou eliminá-los com ela: os ficheiros e o histórico também, sem possibilidade de recuperação.

## Arrumar os documentos

- Arraste uma linha para mudar a posição de um documento na secção, ou use **Mover para cima** e **Mover para baixo** no menu **…** do documento.
- **Mover para…** coloca-o noutra secção.
- Marque vários documentos para os mover ou eliminar de uma só vez.

**Destacar** põe um documento no topo do quadro, por cima das secções. Para um PDF, é preciso poder publicar PDF; para um documento dinâmico, poder gerir os documentos dinâmicos.

Criar e arrumar as secções exige a permissão de configurar as secções; arrumar os documentos, a de os organizar.
